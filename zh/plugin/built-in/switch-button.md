# 开关按钮 (SwitchButton)

开关按钮插件提供了一个简洁的二态图标，专门用于在控制界面上实现设备的“开”与“关”（或两种预设状态）之间的快速切换。例如：控制车灯亮灭、水泵开关、机械臂张合等。

## 配置选项

在开关插件的配置面板中，您可以自定义按钮的图标样式，并精确指定它在不同状态下发送给设备的数值。

> 🖼️ **配置界面截图占位符**：[替换为实际的配置界面截图]

### UI配置
您可以根据按钮控制的具体设备，自定义它在开启和关闭时的显示图标，让界面更直观：
- **开启时图标**：选择一个代表“开启/激活”状态的图标（例如：亮起的灯泡）。
- **关闭时图标**：选择一个代表“关闭/停止”状态的图标（例如：熄灭的灯泡）。

### 控制设置
在这里，您需要绑定按钮控制的设备，并定义“开”与“关”分别代表的具体数值：
- **控制设备**：选择该按钮要控制的目标底层设备。支持选择 PWM 设备、舵机、数字引脚（电平输出）或设备组。
- **开启状态**：设置当按钮处于“开启”状态时，向设备发送的具体数值。
- **关闭状态**：设置当按钮处于“关闭”状态时，向设备发送的具体数值。

*小贴士：系统会根据您选择的设备类型，自动限制“开启”和“关闭”状态可设置的最大值和最小值，确保发送的指令在设备的安全运行范围内。*
