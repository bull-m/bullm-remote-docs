# 键盘控制 (Keyboard)

键盘控制插件允许您使用电脑键盘来控制小车的运动和云台的旋转。通过自定义按键映射，您可以实现类似电脑游戏（如 WASD 移动）的操控体验。此外，该插件还支持设置急行（加速）和缓行（减速）按键，以应对不同的驾驶场景。

## 配置选项

您可以根据自己的操作习惯和小车的底盘类型，在配置面板中自定义速度设置、行动按键以及云台控制方式。

通过配置面板，您可以调整以下设置：

### 速度控制
您可以预设小车的不同行驶速度，并通过组合键进行实时切换：
- **默认速度**：设置小车在正常行驶时的基础速度。
- **Ctrl键急行**：开启此选项后，在按住行驶键的同时按住键盘的 `Ctrl` 键，小车将以“急行速度”行驶。
- **急行速度**：设置按住急行键（Ctrl）时小车的最大速度。
- **Shift键缓行**：开启此选项后，在按住行驶键的同时按住键盘的 `Shift` 键，小车将以“缓行速度”行驶，适合需要精确微调的场景。
- **缓行速度**：设置按住缓行键（Shift）时小车的最低行驶速度。

### 行动按键
根据您小车底盘的类型（系统会自动识别），您可以自定义不同的方向控制按键：
- **坦克底盘**：支持配置 **前进**、**后退**、**左旋**（原地左转）和 **右旋**（原地右转）的按键。
- **麦克纳姆轮底盘**：由于麦轮的特性，除了支持 **前进**、**后退**、**左旋** 和 **右旋** 外，还额外支持配置 **往左**（左侧平移）和 **往右**（右侧平移）的按键。
- **舵机转向底盘**：类似真实汽车，支持配置 **前进**、**后退**、**左转弯** 和 **右转弯** 的按键。

### 云台控制
除了控制小车运动，您还可以配置键盘和鼠标来控制云台：
- **往上**：设置一个键盘按键，按下时云台向上抬起。
- **往下**：设置一个键盘按键，按下时云台向下低头。
- **鼠标滚轮控制俯仰**：开启此选项后，您可以通过滚动鼠标滚轮来快速控制云台的上下俯仰动作。
