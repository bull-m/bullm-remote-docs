# 信号状态 (Signal)

信号状态插件主要用于实时监控和展示小车与控制端之间的网络连接质量及图传状态。

---

## 功能说明

该插件在界面上提供了一个直观的浮动状态栏（或图标），为您展示以下关键信息：

- **小车连接状态**：显示当前控制端是否已成功连接到小车，以及连接是否稳定。
- **实时画面帧率 (FPS)**：显示图传画面的每秒刷新帧数。数值越高代表画面越流畅。
- **丢包率**：显示在视频传输过程中丢失的数据包比例。丢包率过高可能会导致画面卡顿、花屏或延迟。

*注：该插件为纯展示型插件，开箱即用，目前无需进行任何自定义配置。*
