# 图传 (Live)

图传插件的作用是显示小车摄像头的实时画面。该插件提供沉浸式的全屏显示，获得第一人称视角（FPV）的驾驶体验。

## 配置选项

该插件提供了一系列可自定义的画面设置，以适应不同的摄像头安装方式和观看需求。

> 🖼️ **配置界面截图占位符**：[替换为实际的配置界面截图]

通过配置面板，您可以调整以下显示效果：
- **水平翻转** ：将画面水平翻转。
- **垂直翻转** ：将画面垂直翻转。
- **画面填充模式**：可自由选择画面如何适应屏幕。例如保持原比例完整显示（可能留黑边）、保持比例铺满全屏（可能裁剪边缘），或拉伸填满整个屏幕。
- **亮度**：调整画面的明暗程度，以适应不同的环境光线（如较暗或背光环境），确保获得最佳的图传观看体验。
- **对比度**：调整画面的对比度，使画面更清晰、更鲜明
- **饱和度**：调整画面的颜色饱和度，使画面更鲜艳、更鲜艳
